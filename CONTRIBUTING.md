# Contributing

This began as a personal Debian terminal setup, not a large framework. Small, readable fixes are welcome—particularly accessibility tweaks, installation clarity, and compatibility notes.

If you propose a change, please describe the Debian/Konsole/Bash version you tested, explain what the change does, and include a screenshot when it affects appearance. Please do not commit passwords, machine-specific configuration, private paths, SSH keys, or downloaded font files.

AI-assisted contributions are fine. Please review and test any suggested commands before opening a pull request, and describe substantive assistance when relevant.
